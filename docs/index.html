// the problem

Agents forget who they are.

Every time your agent moves to a new environment, it loses context. Memory, personality, skills — gone. Developers are duct-taping agent state together across sessions with no standard format.

Today

Hardcode personality into every system prompt. Copy-paste tool configs across environments. Lose memory on session end.

With AgentFS

One identity directory. Mount it anywhere. Your agent knows who it is, what it remembers, and what it can do — instantly.

Today

Re-define agent personality in every deployment. Build custom skill registries per team with no sharing.

With AgentFS

Plain files. Git-diffable. Human-readable. git clone your agent. Share soul.md on GitHub.

// how it works

One directory. Everything your agent needs.

AgentFS mounts a local directory as a FUSE filesystem with enforced permissions. Read-only where it matters. Append-only where memory grows. The kernel enforces the rules — no agent can overwrite its own soul.

// directory layout
my-agent/
├─ agentfs.yaml     # manifest
├─ soul.md          # identity
├─ mem/
│  └─ episodic.jsonl # memory
├─ skills/
│  └─ web-search.md  # skills
└─ logs/
   └─ session.log    # audit
Path Agent Human
soul.md read edit
mem/episodic.jsonl append edit
skills/*.md read edit
logs/* read + write read
soul.md 
---
name: ResearchAgent
version: 1.0
created: 2026-03-27
---

# Identity
You are a research assistant specializing in technical due diligence.
You are thorough, skeptical, and always cite your sources.

# Behavioral rules
- Always verify claims with at least 2 sources
- Flag uncertainty explicitly
- Prefer primary sources over summaries
// integration

Two lines. Any framework.

AgentFS is framework-agnostic. It's a filesystem — your agent uses it the same way it opens any file. No SDK. No API key. No vendor lock-in.

Python · startup 
# Inject soul into system prompt at startup
with open("/agentfs/soul.md") as f:
    soul = f.read()

system_prompt = soul + "\n\n" + your_base_prompt
Python · memory 
# Append a memory entry after each session
import json, datetime

entry = {
    "ts":   datetime.datetime.utcnow().isoformat() + "Z",
    "text": "Completed competitive analysis of AgentFS vs Hermes",
    "tags": ["research", "decision"],
}

with open("/agentfs/mem/episodic.jsonl", "a") as f:
    f.write(json.dumps(entry) + "\n")
Shell · setup 
# Install
go install github.com/aaron/agent-fuse/cmd/agentfs@latest

# Create an identity
agentfs init ./my-agent

# Mount
agentfs mount ./my-agent /agentfs

# Unmount
fusermount -u /agentfs
